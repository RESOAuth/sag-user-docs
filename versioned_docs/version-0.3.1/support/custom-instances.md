# Custom instances and professional services

The [shared hosted gateway](../hosted/index.md) and
[running SAG yourself](../self-host/quickstart.md) are not the only two
options. RESOAuth® can also run a dedicated instance for you, or help you
configure one you run.

## A dedicated instance on your own domain

A dedicated instance is a SAG deployment RESOAuth runs for you, reachable at
an issuer URL on your own domain rather than the shared
`auth.resoauth.cloud`. It gets whichever upstream tenants, branding, and
client registrations your organisation needs, without you running the
software yourself.

## Configuration help

If you are running SAG yourself and want help choosing upstream providers,
whitelabelling the sign-in screens, or working through the
[configuration reference](../reference/configuration.md), that is available
as paid work too.

## Getting a quote

[Get in touch](./index.md) with what you need. There is no self-service form
for this yet, so the first reply will be a person asking what your
application and organisation actually require.
